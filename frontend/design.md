# Finance QA 프론트엔드 — 현재 UI 디자인 문서

> 대상 파일: [src/app/page.tsx](src/app/page.tsx), [src/hooks/useSSE.ts](src/hooks/useSSE.ts)
> 이 문서는 "지금 코드에 실제로 있는 디자인"을 그대로 기록한 것입니다. 새 화면/컴포넌트를 추가할 때 톤을 맞추기 위한 참고용이며, 코드가 바뀌면 이 문서도 같이 갱신해주세요.

---

## 1. 개요

보험사 CS/CX 상담사가 고객 상담 중 옆에 띄워두고 쓰는 **인바운드 보조 화면**입니다. 페이지 라우팅 없이 `page.tsx` 하나가 전체 화면(SPA)이고, 좌측엔 지금 상담 중인 고객 정보, 우측엔 AI에게 질문하는 채팅창과 원본 문서 뷰어가 탭으로 붙어 있습니다.

## 3. 디자인 토큰

코드에 별도 테마 파일(`tailwind.config` 커스텀 팔레트)은 없고, **Tailwind 기본 팔레트를 의미별로 규칙적으로 사용**하는 방식입니다.

### 색상 — 의미별 매핑

| 의미 | 색상 | 대표 사용처 |
|---|---|---|
| 브랜드/주요 액션 | `indigo-600` → `blue-600` 그라디언트 | 로고 배지, 활성 탭, 전송 버튼, 상담사 말풍선 |
| 배경 | `slate-50` → `blue-50/20` → `indigo-50/30` 그라디언트 (`bg-gradient-to-br`) | `<main>` 전체 배경 |
| 카드/패널 | `white` bg + `border-slate-200` | 사이드바 섹션, 탭 콘텐츠, 모달 |
| 본문 텍스트 | `slate-800` / `slate-900`(강조) / `slate-500`(보조) / `slate-400`(placeholder) | 전반 |
| 성공/정상 상태 | `emerald-50/600/700` | "정상" 배지 |
| 경고/주의 | `amber-50/800/900` | CAUTION 블록 |
| 위험/삭제 | `rose-50/600/700` | "대화 초기화" 버튼, 👎 피드백 |
| 정보/검색결과 | `blue-50/70`, `blue-200`, `blue-900` | RETRIEVAL_RESULT 블록, citation 모달 |
| 코드/디버그 | `slate-900` bg + `emerald-400` 텍스트(터미널 느낌) | Raw JSON 뷰, 디버그 로그 모달 |

> 팔레트 원칙: **indigo/blue = AI·브랜드, slate = 중립/구조, emerald = 정상, amber = 주의, rose = 위험/파괴적 액션.** 새 컴포넌트 추가 시 이 매핑을 따르면 톤이 깨지지 않습니다.

### 타이포그래피

- 거의 전 영역이 `text-xs`(12px) 기준. 그보다 작은 보조 텍스트는 임의값 `text-[10px]` / `text-[11px]`.
- 섹션 제목: `text-sm font-bold`
- 페이지 타이틀(헤더 로고 옆): `text-base font-bold` (텍스트 그라디언트 없음, 단색 `slate-900`)
- 폰트는 Next.js 기본(`font-sans`), 별도 웹폰트 로드 없음.

### 여백 · 모서리 · 그림자

- 카드/패널 라운드: `rounded-2xl` (큰 컨테이너), `rounded-xl`(중첩 카드), `rounded-lg`(버튼/뱃지)
- 카드 내부 패딩: `p-4` ~ `p-5`
- 카드 간 간격: `space-y-3` ~ `space-y-4`, 그리드 갭 `gap-5`
- 그림자: `shadow-xs`(기본 카드), `shadow-sm`(버튼/아바타), `shadow-md`/`shadow-2xl`(모달)
- 배지(badge): `rounded-full px-2 py-0.5 text-[10px] font-semibold` + 의미색 조합

### 아이콘

별도 아이콘 라이브러리 없이 **이모지를 아이콘처럼 사용** (🔮 라우팅, ⚖️ 평가, 🤖 AI 응답, 🐛 디버그, 📄 문서, 👍👎 피드백 등). SVG는 스피너·원형 진행률 표시에만 인라인으로 직접 그림.

## 4. 컴포넌트 인벤토리

### 4.1 Header
로고 배지(그라디언트 사각형, "AIQ") + 타이틀 + "인바운드" 필(pill) 배지 + 서브타이틀. 우측엔 "유저 모드" 토글 스위치.
- ⚠️ 유저 모드 토글은 **시각적 스위치일 뿐 백엔드/로직에 연결되어 있지 않음** (state만 토글, 아무 데도 안 씀).

### 4.2 사이드바 카드 — 고객 정보
아바타(이니셜 원형, 그라디언트) + 이름/생년월일/전화 + 우상단 "정상" 상태 배지. **전부 하드코딩된 단일 고객(`DEFAULT_CUSTOMER`)**.

### 4.3 사이드바 카드 — 가입 상품 정보
"총 N건" 카운트 배지 + 계약 카드(현재 1개 고정):
- 계약 번호 배지(`계약 1`, 다크 배지) + 상태 점(dot) + 📄 아이콘 버튼(→ 문서 탭으로 이동 + 자동 로드)
- 상품명, 가입일
- "계약 요약 (N건)" — `tasks/{task}/enrolled_sections.json`의 실제 가입 특약 목록을 스크롤 리스트로 표시 (역시 하드코딩된 배열)

### 4.4 상단 탭 바
좌측 그룹: `AIQ` 탭 버튼 + (AIQ가 활성일 때만) `세션 1` 필 + 비활성화된 `+` 버튼(새 세션, 미구현).
우측 그룹: (문서가 활성일 때만) `보험증권` 필 + `✕` 닫기 + `문서` 탭 버튼.
활성 탭은 `bg-indigo-600 text-white`, 비활성은 `text-slate-500 hover:bg-slate-100`.

### 4.5 AIQ 탭 — 채팅
- **툴바**: Raw JSON 뷰 토글, 대화 초기화(메시지 있을 때만 노출)
- **빈 상태**: 중앙에 반투명(`opacity-[0.07]`) 워터마크 "AI / INSURANCE ADJUSTER" + 안내 문구
- **메시지 버블**
  - 상담사(counselor): 우측 정렬, indigo→blue 그라디언트 배경, 흰 텍스트
  - AI(assistant): 좌측 정렬(사실상 전체 폭), `slate-50/60` 배경 카드. 헤더에 "🤖 AI 손해사정 가이드" + 소요시간 배지 + 🐛 디버그 버튼 + 타임스탬프
- **로딩 인디케이터**: 마지막 assistant 메시지에만, 원형 진행률 링(SVG `strokeDasharray`/`strokeDashoffset`으로 `progress`% 표시) + 실시간 경과초(100ms 간격 갱신) + 펄스 애니메이션 문구
- **답변 블록 4종** (`block_type` 기준, 백엔드가 내려주는 구조화 데이터):
  | 타입 | 색상 | 아이콘 | 용도 |
  |---|---|---|---|
  | `CONTEXT` | white/slate | 📌 | 상황 파악·질의 맥락 |
  | `RETRIEVAL_RESULT` | blue-50/70 | 🔍 | 약관 검색 결과, 항목마다 🔍 citation 버튼(→ 모달) |
  | `CAUTION` | amber-50 | ⚠️ | 유의사항/면책 |
  | `DELIVER` | indigo-50/70 | 📋 | 고객 전달 안내(필요 서류 등) |
- **피드백**: 👍/👎 토글 버튼(메시지별로 하나만 선택 가능, 같은 걸 다시 누르면 해제). 서버 전송은 안 함(로컬 state만).
- **입력창**: 하단 고정, `textarea`(Enter 전송/Shift+Enter 줄바꿈) + 원형 전송 버튼(로딩 중엔 스피너로 교체).

### 4.6 문서 탭 — 보험증권
헤더(고객명 + 상품명) + "약관 PDF 보기" 버튼(→ PDF 모달) + `certificate.md`를 커스텀 마크다운 렌더러(`renderFormattedMarkdown`)로 렌더링. 로딩 중엔 펄스 애니메이션 안내 문구.

`renderFormattedMarkdown`은 라이브러리 없이 직접 파싱하는 **미니 마크다운 렌더러**로, `#`/`##`/`###` 헤딩, `- `/`* ` 리스트, `---` 구분선, `| ... |` 표, 굵게(`**`)만 지원(그 외 마크다운 문법은 처리 안 됨).

### 4.7 모달 3종 (공통 패턴: `fixed inset-0` + `backdrop-blur-xs` 오버레이)
- **Citation 모달**: RETRIEVAL_RESULT 항목의 🔍를 누르면 약관 원문 스니펫 + 페이지 번호 표시
- **디버그 모달**: 파이프라인 단계별 로그(`stepLogs`)를 터미널 스타일로 나열, 세션 ID 일부 표시
- **PDF 모달**: `<iframe>`으로 `/api/v1/policy-pdf/{task}` 그대로 임베드

## 5. 상태 & 인터랙션 요약

| 상태 | 트리거 | 표현 |
|---|---|---|
| 빈 채팅 | 메시지 0개 | 워터마크 + 안내 문구 |
| 스트리밍 중 | `isLoading=true` | 원형 progress 링 + 실시간 초시계 + pulse 텍스트 |
| 되묻기(slot filling) | 응답에 "입원 일수"/"Slot Filling"/"추가 정보" 포함 | 다음 입력을 일반 질문이 아니라 슬롯 답변으로 전송(`sendSlotFill`), placeholder 문구 변경 |
| 문서 지연 로딩 | 문서 탭 최초 진입 | `certificate.md` fetch, 로딩 중 펄스 문구 |
| 탭 전환 | 상단 탭 클릭 / 사이드바 📄 아이콘 | `mainTab` state, 문서 탭 이동 시 자동으로 `loadPolicyDoc()` 호출 |

## 6. 알려진 한계 (다음에 손볼 지점)

- **다중 고객 미지원**: 고객 정보·가입 상품·특약 목록이 전부 `jang` 한 명 기준 하드코딩. 여러 고객을 다루려면 이 부분을 `/api/v1/...` API 연동으로 바꿔야 함.
- **"세션 1" `+` 버튼**: 새 세션 추가 UI만 있고 실제 다중 세션 관리 로직은 없음(`disabled`).
- **유저 모드 토글**: 아무 동작도 하지 않는 시각적 껍데기.
- **피드백(👍👎)**: 서버로 전송되지 않고 로컬 state에만 존재.
- **마크다운 렌더러**: 커스텀 미니 파서라 표준 마크다운(중첩 리스트, 코드블록, 링크 등) 미지원.
